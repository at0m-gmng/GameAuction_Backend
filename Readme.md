# GameBackend

Высоконагруженная система мат-матчинга и аукциона для игровой платформы.

## Архитектура проекта

Проект использует микросервисную архитектуру с разделением по бизнес-доменам:

### Сервисы

#### Identity.API
- **Назначение**: Аутентификация и авторизация пользователей
- **Функции**: Регистрация, вход, выдача JWT-токенов, управление сессиями
- **Технологии**: ASP.NET Core, JWT Bearer Authentication

#### Catalog.API
- **Назначение**: Управление каталогом товаров/предметов
- **Функции**: Просмотр списка товаров, поиск, фильтрация, получение деталей
- **Технологии**: ASP.NET Core, PostgreSQL, EF Core

#### Ordering.API
- **Назначение**: Обработка заказов и транзакций
- **Функции**: Создание заказов, проверка наличия, обработка платежей
- **Технологии**: ASP.NET Core, RabbitMQ, паттерн Outbox

#### SharedKernel
- **Назначение**: Общие типы и контракты
- **Содержимое**: Доменные сущности, события, DTO, общие утилиты
- **Использование**: Все сервисы ссылаются на эту библиотеку

### Принципы проектирования

- **Изоляция сервисов**: Каждый сервис независим и может разворачиваться отдельно
- **Единая точка отказа**: Отказ одного сервиса не влияет на другие
- **Асинхронная коммуникация**: Сервисы общаются через сообщения, а не синхронные вызовы
- **Идемпотентность**: Повторные запросы не создают дубликатов

## Технологический стек

- **Платформа**: .NET 8 LTS
- **Язык**: C#
- **Базы данных**: PostgreSQL
- **Брокер сообщений**: RabbitMQ
- **Контейнеризация**: Docker
- **Тестирование**: xUnit, Testcontainers
- **CI/CD**: GitHub Actions
